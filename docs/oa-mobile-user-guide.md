# GoWind OA 移动端使用教程

本教程面向手机端用户，讲清楚每个页面能做什么、申请怎么提交、审批怎么处理、打卡怎么打。环境的启动与登录配置见 [快速上手](./oa-quick-start.md)。

## 登录

打开 App 即是登录页，输入账号密码即可。当前版本移动端登录固定走平台租户，**只有平台超级管理员账号（演示环境 `admin` / `admin`）能登录 App**；企业租户的日常用户请暂用管理后台网页端。这个限制后续版本会放开。

## 主界面

底部四个 Tab：

| Tab | 内容 |
|-----|------|
| 工作流 | 审批任务列表（默认首页） |
| 通知 | 站内信收件箱 |
| 考勤 | 打卡与近 30 天记录 |
| 我的 | 个人信息、设置、退出登录 |

在工作流 Tab 里发起申请有两个入口：

- 右上角「⋮」弹出菜单：请假、费用报销、出差、加班、用印、外出、通讯录、通用申请；
- 右下角「＋」悬浮按钮：直达通用申请。

## 审批

工作流 Tab 内有三个子页签：**待我审批 / 已办 / 我发起的**。

**处理待办**：在「待我审批」点一条任务进详情页，能看到申请表单内容（键值对展示）和完整审批轨迹（谁在什么时候提交/同意/驳回/转交/撤回，附意见）。底部操作：

| 按钮 | 作用 |
|------|------|
| 同意 | 通过当前任务；会签节点需全员通过，或签节点一人通过即推进 |
| 驳回 | 整个申请立即变为「已驳回」 |
| 转交 | 弹窗输入对方用户 ID，把任务转给TA处理 |

三个操作都可以在输入框附一句审批意见。处理完自动返回列表。

**跟踪与撤回**：「我发起的」里能看到自己提交的所有申请的状态（进行中/已通过/已驳回/已撤回）；进行中的申请可以**撤回**（确认后流程终止，已产生的待办任务同时取消）。

## 发起申请

### 请假

选请假类型、起止日期，每天可选**上午 / 下午**（支持半天假，如只请某天下午 = 0.5 天）、填事由。页面下方直接显示**当前假种的额度余额**和你的历史请假单。提交后自动走 `LEAVE` 流程，审批通过会自动扣额度；驳回、撤回不扣。

### 费用报销

填报销事由，然后逐行添加费用明细（类别、金额、说明，可增删，总额自动合计）。每行明细可以**拍照或从相册选发票**上传，上传成功自动关联到该行。提交后走 `EXPENSE` 流程。

### 出差 / 加班 / 用印 / 外出

四类表单各配业务字段：出差（目的地、行程说明）、加班（补偿方式下拉）、用印（印章类型、文件份数、收件方）、外出（目的地）。提交后分别走对应流程；这四类审批通过只改单据状态，无额度扣减。

### 通用申请

对任意一条启用的流程定义发起申请：输入流程**编码和版本**（如 `LEAVE:1`）→ 点「加载表单」→ App 会按定义里的表单 Schema 动态渲染出表单（文本 / 多行 / 数字 / 日期 / 下拉，必填项带星号校验）；该定义没配表单 Schema 时回退为自由 JSON 输入。适合流程管理员测试新定义，或接入尚未做专属页面的流程。

## 考勤打卡

考勤 Tab 中部一个大按钮：

- 当天**第 1 次**点击 = 上班签到；
- 当天**第 2 次**点击 = 下班签退，并当场结算当日结果。

打卡时 App 会采集高精度 GPS 定位，并尽量读取当前连接的 Wi-Fi 信息（用于和管理后台配置的地理围栏、Wi-Fi 指纹比对）。所以首次使用需要允许定位权限；拒绝或定位服务未开会有明确提示，去系统设置开启即可。

按钮下方的「**近 30 天记录**」列出每天的签到/签退时间和当日结果。结果的含义：

| 结果 | 含义 |
|------|------|
| 正常 | 打卡齐全且无迟到早退 |
| 迟到 / 早退 | 晚于上班时间打卡 / 早于下班时间打卡 |
| 缺勤 | 工作日全天无打卡记录（由每日结算判定） |
| 请假 | 当天有审批通过的请假覆盖 |
| 待定 | 尚未结算或信息不完整 |

> 每天凌晨有定时任务自动结算前一日；当天结果以最近一次结算为准，管理后台也可手动补算。

## 通知

站内信收件箱：标题、发件人、时间，支持下拉刷新。你经手的申请被推进（收到新待办、你发起的申请有审批结果）时，系统会给你发通知。当前版本通知为列表刷新获取，无实时推送。

## 通讯录

上半部分是**组织架构树**，逐级展开部门；下半部分是全员列表，显示每人所在部门与职位。部分敏感字段（手机号等）按权限脱敏显示。

## 我的

- **个人信息**：查看账号、租户、部门、职位、角色；可编辑昵称、真实姓名、手机号、邮箱等；可修改密码。
- **设置**：主题模式（浅色/深色/跟随系统）、主题色、界面语言（简体中文 / English），即时生效。
- **退出登录**：清除本机登录状态。

## 常见问题

| 现象 | 处理 |
|------|------|
| 打卡提示无定位权限 | 系统设置里给 App 开定位权限；室内定位慢时到窗边或稍等几秒重试 |
| 打卡按钮转圈很久 | GPS 采集超时（约 10 秒）会提示重试；确认定位服务已开启 |
| 提示登录过期 | App 会自动用刷新令牌续期；只有在长期未使用后才需要重新登录 |
| 通知没有实时弹 | 当前版本为下拉刷新获取，收件箱页面拉一下即可 |
| 「我发起的」里看不到刚提交的 | 列表刷新后再看；仍没有说明提交失败，页面会有错误提示 |
